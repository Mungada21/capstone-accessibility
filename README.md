# Automated and AI-Assisted Web Accessibility Assessment

## Project Overview

This project investigates automated and AI-assisted web accessibility assessment compared with manual WCAG audits.

## Dataset

AccessGuru dataset.

Original dataset files are stored in:
data/raw/accessguru/

Processed datasets are stored in:
data/processed/

## Project Structure

- data/raw: Original, unmodified datasets
- data/processed: Cleaned and prepared datasets
- notebooks: Data exploration and experiments
- src: Application and machine learning source code
- docs: Dataset report and WCAG audit rubric

## Important

Never modify the original dataset files. Perform all cleaning and preprocessing on copies.
